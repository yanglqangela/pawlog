# 🐾 爪迹 PawLog

> 养宠成长记录与社区 —— 把散落在疫苗本、聊天记录、相册里的养宠信息，收拢到一处。

🔗 **在线访问**：https://yanglqangela.github.io/pawlog/

---

## 它解决什么问题

| 痛点 | 对应功能 |
|------|---------|
| 疫苗本、聊天记录、备忘录、相册四散，找一次打针记录要翻半天 | 宠物档案 + 健康记录集中管理 |
| 忘了驱虫/疫苗到期日，到了医院才被提醒 | 今日待办：到期倒计时自动提醒 |
| 想知道「我家猫是不是太胖了」，没有参照系 | 体重曲线 + 品种标准区间对照 |
| 想晒娃但朋友圈都是同事，想找同城宠友没渠道 | 附近宠友（地域匹配）+ 社区动态 |
| 成长瞬间没沉淀，一年后记不清哪天学会握手 | 成长时间线 + 里程碑 + 分享卡片 |

## 功能结构

```
爪迹 PawLog
├── 首页 ── 今日待办 · 宠物概览 · 健康速览 · 最近瞬间 · 附近宠友
├── 健康档案 ── 体重曲线 · 疫苗 · 驱虫 · 就诊（均可增删改）
├── 成长时光 ── 时间轴 · 里程碑 · 分享成长卡片
├── 附近宠友 ── 地域筛选 · 宠友名片墙 · 同城活动报名
└── 社区 ── 动态流 · 话题广场 · 发布 · 点赞评论
```

## 技术选型

零依赖的纯静态站点：**原生 HTML / CSS / ES Modules**，无构建步骤、无 CDN 依赖。

- 路由：hash 路由（静态托管下刷新不 404）
- 数据：localStorage 持久化，首访填充示例数据
- 图表：手写 SVG，无图表库
- 部署：GitHub Pages

选择理由：这是一道产品设计题，优先保证**链接永远打得开**。没有构建产物、没有外部依赖，就没有「本地能跑、线上白屏」的风险。

## 本地运行

ES Modules 需要通过 HTTP 访问（`file://` 会因 CORS 被拦截）：

```bash
python -m http.server 8777
# 打开 http://localhost:8777
```
