# 🐾 爪迹 PawLog

> 养宠成长记录与社区 —— 把散落在疫苗本、聊天记录、相册里的养宠信息，收拢到一处，并在**真正需要它的时刻**能立刻拿出来。

🔗 **在线访问**：https://yanglqangela.github.io/pawlog/

---

## 它解决什么问题

养宠的人不会"为了用工具而用工具"。真正会打开它的时刻只有几个，这个产品围绕这几个时刻设计：

| 真实场景 | 爪迹怎么做 |
|---|---|
| **宠物急诊，医生问「疫苗打了吗？」「有过敏史吗？」** | **就医模式**：一屏给出全部关键信息，过敏史红色高亮，可一键复制成文本发给医生 |
| 打完针/驱完虫，回家记一笔 | 极简录入：日期默认今天、下次日期按周期自动算好；或直接在提醒卡上点「今天做了」顺延 |
| 该驱虫了，想不起上次什么时候 | 首页待办倒计时 + 标签页标题带红点数字 |
| 想知道「我家猫是不是太胖了」 | 体重曲线 + 品种标准区间对照，直接给「偏轻/理想/偏重」结论 |
| 成长瞬间没沉淀，一年后记不清哪天学会握手 | 成长时间线：健康记录自动汇入，里程碑可标星并生成分享卡片 |
| 想找同城宠友遛狗 | 按城市/区域匹配宠友名片墙 + 同城活动报名 |
| 「我记了半年的数据会不会没」 | 「我的」页一键导出/导入 JSON 备份 |

## 功能结构

```
爪迹 PawLog
├── 首页     ── 今日待办（可一键打卡）· 宠物概览 · 健康速览 · 最近瞬间 · 附近宠友
├── 健康档案 ── 体重曲线 · 疫苗 · 驱虫 · 就诊（均可增删改，日期智能预填）
├── 成长时光 ── 时间轴（健康记录自动汇入）· 里程碑 · 分享成长卡片
├── 附近宠友 ── 地域筛选 · 宠友名片墙 · 同城活动报名
├── 社区     ── 动态流 · 话题广场 · 发布 · 点赞评论
└── 我的     ── 个人资料 · 我的宠物 · 我的动态 · 数据备份导出/导入
        └── 宠物档案页（#/pet/:id）
              ├── 基本信息 + 过敏史 / 芯片号 / 常去医院 / 体重目标
              ├── 就医模式 🚨
              └── 待办一键顺延
```

## 几个产品决策

**「就医模式」为什么是最高优先级。**
这是唯一一个「记录的价值在关键时刻才兑现」的场景。平时记了半年疫苗和驱虫，医生问的时候拿不出来，等于没记。所以它被做成一个独立入口：高对比、大字、少装饰，一屏看完基本信息、过敏史、疫苗史、驱虫史、既往病史、常去医院，外加数据更新时间戳（医生需要知道数据新旧）。

**「一键顺延」而不是「填表」。**
驱虫是每月重复动作，每次都要填 4 个字段是设计事故。真正的动作是「打卡」——点一下，系统按 30 天周期自动算出下次日期。

**时间线是「生成」的，不是「手录」的。**
题目要求「**生成**成长时间线」。疫苗、驱虫、就诊作为离散事件自动进轴；体重是连续量，逐条铺上去会变成流水账，所以**按月汇总**成一条（`3 次记录，4.7 kg → 4.8 kg（+0.1）`）。手动只补里程碑，不再重复录入。

**诚实标注能力边界。**
纯静态站点做不到系统级推送，所以在「关于」里明说了：到期提醒需要打开本页面才能看到，真实产品中会通过 App 推送解决。不假装能做到。

## 技术选型

零依赖的纯静态站点：**原生 HTML / CSS / ES Modules**，无构建步骤、无 CDN 依赖。

- 路由：hash 路由（静态托管下刷新不 404），支持 `:param`
- 数据：localStorage 持久化，读旧数据时做 `normalize()` 补齐新字段
- 图表：手写 SVG，无图表库

选择理由：这是一道产品设计题，优先保证**链接永远打得开**。没有构建产物、没有外部依赖，就没有「本地能跑、线上白屏」的失败模式。

**一个踩过的坑**：日期一律不能用 `toISOString()` —— 它返回 UTC 日期，东八区的本地 00:00 会变成前一天 16:00，结果是「凌晨打开时今天变成昨天」、周期推算整体早一天。统一走本地时区的 `parseISO` / `toISO`。

## 本地运行

ES Modules 需要通过 HTTP 访问（`file://` 会因 CORS 被拦截）：

```bash
python -m http.server 8777
# 应用：http://localhost:8777
# 自检：http://localhost:8777/tests/self-check.html
```

## 自检

`tests/self-check.html` 是一个浏览器内跑的断言页（19 项），覆盖：就医卡渲染、就医文本导出、时间线自动聚合与同月折叠、周期推算、一键顺延、备份导出导入往返、旧版本数据兼容、坏文件拒绝。打开即可看到 PASS/FAIL 列表。
