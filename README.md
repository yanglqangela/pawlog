# 🐾 爪迹 PawLog

> 养宠成长记录与社区 —— 把散落在疫苗本、聊天记录、相册里的养宠信息，收拢到一处，并在**真正需要它的时刻**能立刻拿出来。

🔗 **在线访问**：https://yanglqangela.github.io/pawlog/

📊 **项目状态**：[STATUS.md](STATUS.md) —— 进度、验收结果、已知限制与下一步。

---

## 它解决什么问题

养宠的人不会"为了用工具而用工具"。真正会打开它的时刻只有几个，这个产品围绕这几个时刻设计：

| 真实场景 | 爪迹怎么做 |
|---|---|
| **宠物急诊，医生问「疫苗打了吗？」「有过敏史吗？」** | **急救 / 就医模式**：一屏给出过敏、慢病、当前用药、疫苗驱虫、最近就诊、费用与数据更新时间；可打印、复制、分享 |
| 打完针/驱完虫，回家记一笔 | 极简录入：日期默认今天、下次日期按周期自动算好；或在提醒卡上点「今天做了」顺延，连点只记一次 |
| 该驱虫了，想不起上次什么时候 | 首页待办置顶 + 标签页标题数字；可导出 `.ics` 到系统日历，由日历提前 3 天和当天提醒 |
| 想知道「钱花在哪儿了」 | 费用台账（按年/月/类别）+ 理赔材料包，可打印或另存 PDF |
| 猫老了，需要更密的观察 | 老年模式：用药打卡、症状日记、生活质量 7 项评分与趋势、复诊提醒 |
| 出差，要把猫托付给别人 | 寄养交接卡（喂食/用药/禁忌/联系人/医院）+ 出行证件包，可打印/复制/分享 |
| 猫走失了 | 走失模式：一屏海报 + 可下载 PNG + 可复制文案；首页红色横幅提醒 |
| 换手机、误删除 | 「我的」备份中心：IndexedDB 自动快照（最近 10 版 + 每日 1 版）+ JSON 导出/合并导入 |
| 「我记了半年的数据会不会没」 | 写入失败有常驻横幅；导入先校验、可回滚；删除可撤销 |
| 想找同城宠友遛狗 | 按城市/区域匹配宠友名片墙 + 同城活动报名（全部标注「演示」） |

## 功能结构

```

```

## 几个产品决策

**「就医模式」为什么是最高优先级。**
这是唯一一个「记录的价值在关键时刻才兑现」的场景。平时记了半年疫苗和驱虫，医生问的时候拿不出来，等于没记。所以它被做成一个独立入口：高对比、大字、少装饰，一屏看完基本信息、过敏史、慢病、当前用药、疫苗史、驱虫史、最近症状、既往病史、常去医院，外加数据更新时间戳（医生需要知道数据新旧）。

**「一键顺延」而不是「填表」。**
驱虫是每月重复动作，每次都要填 4 个字段是设计事故。真正的动作是「打卡」——点一下，系统按 30 天周期自动算出下次日期；同一周期重复点击只保留一条记录。

**时间线是「生成」的，不是「手录」的。**
题目要求「**生成**成长时间线」。疫苗、驱虫、就诊作为离散事件自动进轴；体重是连续量，逐条铺上去会变成流水账，所以**按月汇总**成一条（`3 次记录，4.7 kg → 4.8 kg（+0.1）`）。手动只补里程碑，不再重复录入。

**诚实标注能力边界。**
纯静态站点做不到系统级后台推送，所以提醒有两条路：打开页面看到待办，或导出 `.ics` 交给系统日历。应用可安装到桌面、断网也能打开档案与就医卡，但**不假装**能做后台推送、实时多人或真实交易。社区/附近内容全部标注「演示」，可一键清空。

**医疗安全边界：只整理，不诊断。**
急诊红旗用静态规则（呼吸困难、抽搐、猫 24 小时不排尿等），不交给模型；用药页只记录兽医处方，不提供剂量建议；所有就医卡都带免责声明。

## 技术选型

零依赖的纯静态站点：**原生 HTML / CSS / ES Modules**，无构建步骤、无 CDN 依赖。

- 路由：hash 路由（静态托管下刷新不 404），支持 `:param`
- 数据：localStorage 持久化（`schemaVersion: 2`），读旧数据时 `normalize()` 补齐字段；写入失败可见
- 备份：IndexedDB 快照环 + JSON 导入校验 / 合并 / 回滚
- 离线：`manifest.webmanifest` + Service Worker 预缓存 app shell；新版本就绪时提示刷新
- 提醒：RFC 5545 `.ics`（VEVENT / VALARM / RRULE），交给系统日历
- 图表：手写 SVG，无图表库

选择理由：这是一道产品设计题，优先保证**链接永远打得开**。没有构建产物、没有外部依赖，就没有「本地能跑、线上白屏」的失败模式。

**一个踩过的坑**：日期一律不能用 `toISOString()` —— 它返回 UTC 日期，东八区的本地 00:00 会变成前一天 16:00，结果是「凌晨打开时今天变成昨天」、周期推算整体早一天。统一走本地时区的 `parseISO` / `toISO`。

## 明确不做（原型阶段）

- 后端 / 数据库 / 账号 / 实时同步 / 多端
- 真实社区审核、IM、交易担保、保险销售
- AI 诊断、用药剂量建议、医疗导流
- 照片上传 / OCR / 实时 POI 抓取（先用 emoji 占位、示例地点 + 地图跳转）
- 二维码生成（寄养卡/海报先用文本与打印）

## 本地运行

ES Modules 与 Service Worker 需要通过 HTTP 访问（`file://` 会因 CORS 被拦截）：

```bash
python -m http.server 8777
# 应用：http://localhost:8777
# 自检：http://localhost:8777/tests/self-check.html
```

首次打开后 Service Worker 生效；断网刷新仍可打开首页、档案与就医卡。Chrome/Edge 地址栏可出现「安装」入口，iPhone 用 Safari 分享 → 添加到主屏幕。

## 自检

`tests/self-check.html` 是一个浏览器内跑的断言页（110 项），覆盖：就医卡渲染与 XSS 转义、就医文本导出、时间线自动聚合与同月折叠、本地日期、周期推算、一键顺延幂等、记录/症状/用药/费用/保单/生活质量 CRUD 与撤销、导入校验与合并、旧数据兼容、清空演示内容、走失海报、表单 label、ICS 结构与转义、PWA manifest 与 Service Worker 资源，以及**自检不污染生产数据**。

打开即可看到 PASS/FAIL 列表；标题为 `TESTS_OK` 表示全部通过。
